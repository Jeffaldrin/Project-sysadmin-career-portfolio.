# Web-Based System Administrator Career Portfolio

A responsive student portfolio built with plain HTML, CSS, and JavaScript using a dark terminal-inspired design.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, colors, responsive styling, and animations
- `script.js` — mobile navigation, active-section highlighting, and footer year

## Run locally
1. Extract the ZIP file.
2. Open the `sysadmin_career_portfolio` folder.
3. Double-click `index.html` to open it in a modern browser.

No database, login, build tools, or installation is required. An internet connection is only needed for the optional Google Fonts import and external documentation links.

## Personalize before submitting
In `index.html`, find the About the Developer section and replace:
- `Your Name`
- `Your Course / Program`
Also adjust the About text so it accurately describes you.

## Publish online
You can upload the three website files to a static host such as GitHub Pages or Netlify. Submit the resulting public URL if your instructor requires one.

## Screenshots
Open the site in a browser and take screenshots of:
1. Home / hero section
2. Roles & Responsibilities
3. Skills
4. Tools
5. About the Developer
For a full-page screenshot, use your browser's built-in screenshot or developer tools.

## Requirement checklist
- Home, navigation, and introduction: included
- At least five responsibilities: six included
- At least five technical/professional skills: six included
- At least five tools/technologies: six included
- About the Developer: included with placeholders to personalize
- Responsive desktop/mobile layout: included
- Working navigation and external documentation links: included
- Source code: HTML, CSS, and JavaScript provided
